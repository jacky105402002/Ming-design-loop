# Figma 操作接口

本流程規定產物與證據，不綁定單一 MCP。工具名稱、API、方案限制與連線方式以本次實際工具文件為準；不要把本文件當成永久有效的 API 規格。

## 連線與權限

1. 先查本次可用工具，確認具備哪些能力：讀文件／節點、讀元件與變數、截圖、建立／修改設計、匯出素材、原型互動。MCP 名稱存在不表示服務已連線，更不表示有寫入權限。
2. 以唯讀狀態與文件資訊核對目標檔案、分支、頁面及存取範圍。避免把使用者另開的作用中文件當成本次目標。
3. 已明確要求在指定 Figma 檔案設計，且工具權限允許，就在授權區域持續執行，不逐個畫框請求確認。若目標、內容傳送範圍或新建檔案位置有重要歧義，先問缺少資訊。
4. 新建文件、分享權限、發布元件庫、外部素材上傳與帳號設定分別核對授權。設計任務不自動授權變更其他人的分享權限或安裝本機軟體。

## 可選工具路徑

### Figma Console MCP（第三方）

本機可用此工具時，適合可編輯畫框、文字、Auto Layout、元件、變數與結構檢查。需要的 Desktop Bridge 與工具依賴由目前官方文件確認；先用狀態工具驗證，不因看見工具清單便宣告橋接成功。

依當前工具指引使用狀態／搜尋／讀取／寫入／截圖能力。優先批次處理相關變數或元件，降低往返。腳本只操作已核對的文件與節點，讀取當前 API／字型資訊，不貼上未驗證的第三方程式。

### 其他 Figma 連接器

如果提供 `use_figma`，執行前載入其要求的 `figma-use`；完整畫面、元件庫、新文件及設計轉程式各自遵守該工具要求的前置技能。這些是依實際提供者選用的前置條件，不是要求所有機器都安裝同一套插件。

只有 `get_design_context` 或讀取能力時，可接收設計與製作交接；不可聲稱能寫回 Figma。官方與第三方工具能力都應以本次實際 schema 為準，不預設官方一定唯讀或第三方一定可寫。

### 無可用寫入能力

完成已授權且可獨立做的需求對照、流程、畫面規格與繪製清單；記錄缺少的連線、目標或工具能力。若要求 Figma 成果，保留 blocked，不偷偷改成圖片、HTML 或其他設計平台當成完成。轉用雲端服務或新工具前核對資料傳送與授權。

## 可編輯稿的要求

- 畫面有明確 Frame／Section 容器，內容位於命名區域內；檢查是否已存在再新增，避免重跑產生重複稿。
- 文字保留文字圖層；圖像、插圖與照片可作圖片素材，不能把整個 UI 截圖當作可編輯設計。
- 有結構關係的容器使用 Auto Layout，核對固定、內容自適應與填滿容器的意圖；適用時使用 constraints。
- 重複元素採既有元件實例；狀態使用變體／屬性或可清楚對照的規格。調整實例優先使用支援的屬性工具，避免直接改字卻未生效。
- 色彩、字體與間距沿用既有變數／樣式，只有必要時新增。不得為套用自己的命名重建客戶元件庫。
- 寫文字前核對字型與實際可用樣式，先載入字型。繁體中文字型缺字時選擇已可用的適當替代並記錄，重要品牌差異請使用者決策。
- 流程圖可放 FigJam；交付為 Figma Design 的線稿與 UI 需在正確文件類型，不能以 FigJam 流程圖冒充畫面稿。

新檔案可按需求建立 Brief、Wireframes、UI、Components、Handoff 區域；這是可調整建議，不強制建立空白頁，也不改外部設計師的既有組織方式。

## 寫入與重試

1. 先讀結構與截圖，核對指定範圍及原有內容。記錄本輪設計 revision、操作區域與基準。
2. 使用具名容器與穩定畫面 ID；每輪返回／記錄實際受影響節點 ID。跨次接續重新確認 ID 與目標仍吻合，不能只相信上次記憶。
3. 將一次操作控制在可檢查、可恢復的範圍，例如一個元件組或一個畫面。不以整個檔案清空重建來修正局部錯誤。
4. 工具失敗或回傳不明時先讀回實際結果，區分完全未寫入、部分完成與已完成但回應失敗。僅補未完成部分。
5. 若需要清理本輪失敗產物，只處理已證實由本輪建立的孤立節點，遵守當前平台刪除規則；不能刪除既有設計、來源稿或其他人的修改。不可確認歸屬時保留並標記。
6. 同一問題三輪仍失敗時停止對該部分寫入，報告證據與下一步；不同問題不能拿來重設同一失敗的重試次數。

## 驗證回圈

**寫入 → 讀回結構 → 截圖檢視 → 集中修正 → 驗證受影響部分。**

結構核對包含節點數、名稱、尺寸、父子關係、元件／變數綁定及重要文字。截圖檢查對齊、溢出、層級、字型、間距與背景。必要時實際走原型；無操作證據時只說互動規格已核對。

一次工具結果可同時提供結構證據，不必為形式重複讀取。修正後已有有效截圖即作最後畫面證據；沒有相關變更不要再重複驗證。

## 版本與來源

記錄 file URL／key、分支（若有）、節點 ID、擷取時間與可用版本識別。如果工具不提供不可變版本，保存本地畫面／結構快照及雜湊，並標註「時間點快照」，不可稱作 Figma 已鎖定版本。

外部設計在交接後更新時，先比較基準再接收。共享元件更新、字型替換或大範圍重排，須重新評估相關畫面與既有證據。

素材匯出需記錄來源、用途及已知授權限制。暫時下載網址不是持久交付；能合法保存的素材放專案資產位置，否則記錄取得方式與待辦，不把已過期連結算交付完成。
